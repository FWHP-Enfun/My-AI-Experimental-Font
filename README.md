# 我的Ai實驗字體 My AI Experimental Font

畫幾百和幾千個中文字非常累，自己用zi2zi總是失敗，我打算去Ai補字網站花錢買他們的技術生字

Drawing hundreds or thousands of Chinese characters is extremely exhausting, and my own attempts using *zi2zi* kept failing. I plan to pay an AI-based character generation service to create the characters I need.

我寫字能力很差，但想像力很好，我叫Chatgpt生成我喜歡風格的字體，然後到Font2Art和字體家AI神筆生成更多字元

My handwriting skills are poor, but I have a vivid imagination. I asked ChatGPT to generate a font style I like, and then used Font2Art and  字體家AI神筆 to generate additional characters.

後來用FontCreator小改一些，補英文字和符號

Later, I made some minor adjustments using FontCreator and added the English characters and symbols.

這裡是材料，Ai生成的字會有錯和混合寫法，如果你喜歡，我歡迎你修改，不過要遵守SIL協議

Here are the materials. AI-generated characters may contain errors or hybrid forms; you are welcome to modify them, provided that you comply with the SIL Open Font License.

這2個Ai補字網站，生出來的東西版權是屬於自己的，可以做開源字體

With these two AI-powered font-completion websites, you own the copyright to the output, allowing you to create open-source fonts.
